# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

energy_kwh 是快检剩余能量，resistance_mohm 为毫欧；完整测试的 life_cycles 为在 test_load_kw 与温度条件下达到初始容量80%之前的循环数。selection_probability 是历史登记的送检概率，不代表未检样本已有标签。成组限定：同柜组化学体系及电压等级一致，最多四模组串联、两串并联；一串可用能量为该串模组数乘最小模组能量，功率不能超过任一模组 power_kw；柜组功率为各串能力之和。环境超出已测范围不得无说明推断。cycle_test 消耗给定循环数，open_test 破坏资产。不得混合不同期限订单的替换预留。安全上限为用户条件而非费用可抵消项。

## modules
模组来源与实物，historical_only为历史分析用且不可交付；完整到阈值试验样本已经耗尽使用资格。

记录键：['module_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| module_id | string | 模组 |
| source_pack | string | 原退役包 |
| batch | string | 拆解批 |
| chemistry | string | 化学体系 |
| voltage | integer | 电压等级伏 |
| received | date | 到货日 |
| purchase_cost | number | 采购元 |
| state | string | available或historical_only |

## quick_tests
